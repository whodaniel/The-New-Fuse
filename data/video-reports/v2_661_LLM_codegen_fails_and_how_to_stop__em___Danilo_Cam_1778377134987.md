## Summary
Danilo from PostHog presents on 'LLM codegen fails and how to stop 'em' at AI Engineer Europe. He discusses how the PostHog Wizard automates integration setup for 15,000 users monthly, reducing 2 hours of manual work to 8 minutes. The talk covers key failure modes of LLM code generation: model rot (outdated training data), improvisation (hallucination), human error, and overengineering. The primary technical solution involves providing fresh, up-to-date documentation via markdown files injected into the agent's context window, rather than relying on RAG, to ensure accurate API usage and integration patterns.
