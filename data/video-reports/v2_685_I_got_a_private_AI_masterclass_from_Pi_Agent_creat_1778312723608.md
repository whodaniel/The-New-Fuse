## Summary
Interview with Mario, creator of PI (pbydev), discussing the evolution of AI coding agents from early LLM tools through Cursor to Claude Code, and why he built his own agentic coding tool after finding existing solutions became bloated and unstable.

## Key Points
- Early LLM coding tools (pre-2024) were limited to individual files with poor codebase context
- Cursor in 2024 improved things but remained file-scoped
- Claude Code's breakthrough was giving agents terminal/bash access for autonomous codebase exploration
- Agentic search emerged as a key paradigm shift in coding agents
- Cloud Code became unusable for the speaker due to feature bloat, token limits, and system prompt changes by mid-2025
- Speaker reverse-engineered Cloud Code (JavaScript app) to understand its internals
- Built PI as a stable, minimal alternative with full user control over non-LLM components
- Small teams with coding agents can outperform much larger teams (6 vs 50-100 people)
- Speaker has background in NLP and machine learning from the 2000s
