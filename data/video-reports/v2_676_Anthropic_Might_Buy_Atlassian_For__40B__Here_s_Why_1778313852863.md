## Summary
Analysis of how issue trackers (Jira, Linear, etc.)—originally built for human software development coordination—are becoming critical infrastructure ('substrate') for AI agents in 2026. The speaker argues that these 'boring' tools encode essential agent needs: state, ownership, permissions, history, and workflow handoffs. This is exemplified by OpenAI's Symphony, an open-source orchestration spec that uses a Linear board as a control plane for autonomous coding agents. The video explores why legacy enterprise tools (Atlassian, Salesforce, ServiceNow) may hold strategic value as agent infrastructure, and how the underlying state machines, audit trails, and dependency graphs of these systems are more valuable than their UIs.
