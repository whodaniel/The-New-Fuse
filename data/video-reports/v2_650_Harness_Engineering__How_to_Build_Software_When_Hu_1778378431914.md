## Summary
Ryan Lopolo (Member of Technical Staff at OpenAI) presents 'Harness Engineering: How to Build Software When Humans Steer and Agents Execute.' He argues that since GPT-5.2, AI models are capable of producing all necessary code, making code itself 'free.' The new scarce resources are human time, human/model attention, and model context window. The role of human engineers shifts from writing code to systems thinking, system design, and delegation—unblocking teams of agents to execute. He advocates for leaning into this 'token billionaire' future where implementation is no longer the bottleneck.
