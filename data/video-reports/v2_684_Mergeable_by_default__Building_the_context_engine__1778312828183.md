## Summary
Technical presentation by Peter and Brandon on context engines for AI agents. The session covers common myths about context engines, lessons learned from building one, and includes a hands-on workshop component where attendees will build a social engineering graph—a key component for providing optimized organizational context to AI agents.

## Key Points
- Session is split into two parts: a talk on context engines followed by a hands-on coding workshop
