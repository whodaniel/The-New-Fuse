## Summary
Technical presentation at AI Engineer Europe conference introducing 'context engines' for AI agents. Speaker Peter (with colleague Brandon) explains that context engineering is the art of supplying necessary context while excluding irrelevant context to optimize agent performance. The session covers three myths about context engines, lessons learned from building one, and includes a workshop component where attendees will build a social engineering graph—a key component of context engines. The presentation emphasizes that agents traditionally start with zero context and waste time 'ripping around' codebases, whereas a proper context engine streamlines execution aligned with organizational best practices.
