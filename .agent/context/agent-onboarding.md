# TNF Open Agent Onboarding

This is a public-runtime bootstrap pointer. It is intentionally compact.

## Entry

Run:

```bash
pnpm run tnf:onboard -- --task "<task>"
```

Before mutation, rerun with `--write-ready` and provide the required classification variables.

1. `.agent/SYSTEM_PROMPT.md`

Use current public runtime state/handoff projections when present, but do not confuse an old handoff with current authority.

## Core semantics

Preserve:

`Intent · Authority · Context · Capability · Boundary · Action · Receipt · Handoff`

and:

`RESPOND → ORIENT → CLASSIFY → HYDRATE → STAFF → ACT → VERIFY → PROPAGATE → HANDOFF`

Capability never implies authority. Context is scoped/fresh. Shared mutation requires ownership/collision awareness. Verification outranks narrative. Missing hosted optimization does not remove local TNF agency.

## Public/private boundary

The open runtime is complete enough to operate locally. Hosted TNF is an optional compatible authority/intelligence provider for capabilities exposed by public contracts.

Do not search for or depend on private TNF source in order to complete ordinary public-runtime work.
