## Formulas

- CAC = total_sales_marketing_spend / new_customers_acquired
- LTV = (average_purchase_value _ average_purchase_frequency _
  average_customer_lifespan_years) \* (gross_margin_percentage / 100)

- Payback period (months) = CAC / average_monthly_gross_profit_per_customer
