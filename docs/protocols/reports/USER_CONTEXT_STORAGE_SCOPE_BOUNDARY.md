# User Context Storage Scope Boundary

This change establishes the shared semantic/profile contract and local resolver/configuration tooling.

It does **not** claim to complete:

- Google Drive OAuth or provider IO;
- hosted thenewfuse.com user storage service;
- Tauri backend commands;
- mirrored synchronization/conflict resolution;
- migration of existing user-owned source data.

Those remain explicit follow-up implementation work and must preserve user ownership/recovery.
