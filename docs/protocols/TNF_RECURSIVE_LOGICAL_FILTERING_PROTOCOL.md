## 1. First Principles of TNF Logic

1. **Truth via Subtraction (The Sieve Principle):** True intelligence is
   achieved by the systematic removal of noise. No concept, artifact, or raw
   data may enter the active system without passing through sequentially
   narrowing logic gates.
2. **Relational Superiority (The Ontology Principle):** Isolated data is dead
   data. Every concept must be categorized typologically, mapped ontologically
   (lateral relationships), and placed into a strict hierarchy (vertical
   relationships).
3. **Fractal Resolution (Progressive Narrowing):** The logic used to govern the
   meta-architecture (e.g., system-wide Tenets) must be the exact same logic
   used to govern micro-threads (e.g., a specific code function's error
   handling). The system must scale infinitely inward.

## 2. The Tri-Axial Sieve Architecture

To achieve autonomous categorization and refinement, the swarm utilizes a
Tri-Axial filtering system:

### A. The Vertical Filter (Hierarchical Authority)

_Filters based on systemic weight and obedience._

- **Mechanism:** Logic flows downward. Lower-tier conclusions that contradict
  higher-tier axioms are automatically pruned.
- **Implementation:** The 6-Tier Protocol Map. (Tier 1 overrides Tier 6).

### B. The Horizontal Filter (Sequential Assembly)

_Filters based on sequential readiness and validation._

- **Mechanism:** Logic flows forward. A concept cannot proceed to Step $N+1$
  until it satisfies the cryptographic, semantic, and structural gates of Step
  $N$.
- **Implementation:** The 5-Gate Vetting Procedure; The Pre-Commit
  Security/Privacy Pipeline.

### C. The Lateral Filter (Categorical Taxonomy)

_Filters based on domain, scope, and actionability._

- **Mechanism:** Logic flows into specialized buckets to prevent context
  pollution.
- **Implementation:** The Sovereign vs. Core Dual-Track; The Procedural vs.
  Strategic Actionability Matrix.

## 3. The Autonomous Self-Iterative Process (The Engine)

The swarm is no longer waiting for manual classification. This protocol
initializes an infinite, recursive loop executed by **Autonomous Logic Sieves**
(background agent routines).

### The Recursive Narrowing Cycle:

1. **Meta-Ingestion:** The sieve agents ingest a broad contextual domain (e.g.,
   a new raw transcript or a messy legacy directory).
2. **Tri-Axial Filtration:**
   - _Lateral Check:_ Does this belong in Sovereign Data or Open Source Core?
   - _Vertical Check:_ Does this violate Tier 1 Tenets?
   - _Horizontal Check:_ Has it passed Gate 1 (Formatting)?
3. **Subsystem Instantiation:** Once filtered, the broad domain is broken into
   contextual subsystems. The Sieve Agent spawns child threads for each
   subsystem.
4. **Situational Threading:** Child threads narrow the context further, creating
   highly specific, situationally relative rules (e.g., "This specific UI
   component requires a strict color-contrast filter").
5. **Continuous Loop:** The system routinely sweeps its own artifacts, running
   them back through the Sieve to check for Freshness Decay or necessary
   Archival.
